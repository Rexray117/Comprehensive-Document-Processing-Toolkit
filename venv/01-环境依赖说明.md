# 01 · 环境依赖说明

> 本文档梳理捆绑包 `venv/` 的来源、组成、移植边界与重建方法。

## 一、解释器与 venv 链路

```
捆绑 venv:  <bundle>/venv/Scripts/python.exe   (Python 3.13.14)
                │  pyvenv.cfg → home
                ▼
基础解释器:  C:\Users\ASUS\.workbuddy\binaries\python\versions\3.13.12   ← 唯一外部依赖
                │  由 WorkBuddy 受管安装
                ▼
原始创建者:  E:\AI agent\workbuddy\resources\vendor\python\python.exe     (venv 创建时的引导程序)
```

venv 的 `pyvenv.cfg` 中 `home` 指向基础解释器目录。**本机内复制可用**（该目录仍存在）；
若要迁移到**没有装 WorkBuddy 的机器**，需先装 Python ≥3.13，再按「第四节」重建。

## 二、依赖构成（116 个包，快照见 `requirements/pip-freeze-snapshot.txt`）

| 层 | 包 | 用途 |
| --- | --- | --- |
| **核心必需（11）** | python-pptx / python-docx / openpyxl | 三大 Office 格式的 ZIP+XML 解析 |
| | pandas / numpy | 数据统计、透视、相关性 |
| | Pillow | 图片元数据与处理 |
| | beautifulsoup4 / lxml | HTML 解析（lxml 优先，失败回退 html.parser） |
| | markdownify / filetype / charset-normalizer | HTML→MD、魔数嗅探、编码探测 |
| **PDF（1）** | pypdf | pdf 模块唯一依赖，纯 Python 离线 |
| **OCR（3+）** | onnxruntime 1.30 / opencv-python 5.0 / rapidocr 系 | rapidocr → tesseract → easyocr 按序自动选用 |
| **可选未装** | pytesseract / easyocr / mammoth / XlsxWriter | 未装不影响任何核心功能 |

## 三、已踩过的版本坑（重要）

1. **`rapidocr-onnxruntime>=1.3.24` 在 Python 3.12+ 无可用发行版**
   `requirements-ocr.txt` 原钉死该版本，pip 会整事务回滚。解法：改装新包
   `rapidocr`（2.x+，`pip install rapidocr onnxruntime`）。`ocr/engines.py` 已内置
   2.x `RapidOCROutput`（boxes/txts/scores）兼容分支，无需改代码。
2. **`edit` 动作默认就地保存**，会在原文件旁生成 `<名称>_bak.<后缀>`；要保留原文件传
   `in_place=false` 或 `output` 指定路径。
3. **Excel 公式单元格可能读到 `null`**：文件从未被 Excel/WPS 打开保存过时公式无缓存值，
   工具会给 warning 并回退显示公式文本，不是空数据。
4. **网络中断续传**：OCR 大包（onnxruntime/opencv）下载可能中断多次，pip 会自动 resume，耐心等即可。

## 四、从零重建环境（换机 / venv 损坏时）

```bash
# ① 装 Python ≥3.13 后创建 venv
python -m venv <bundle>/venv

# ② 按快照精确复原（推荐，与当前环境逐包一致）
<bundle>/venv/Scripts/python.exe -m pip install -r <bundle>/requirements/pip-freeze-snapshot.txt

# ③ 或按需求清单复原（允许版本漂移）
<bundle>/venv/Scripts/python.exe -m pip install -r <bundle>/requirements/requirements.txt
<bundle>/venv/Scripts/python.exe -m pip install rapidocr onnxruntime   # OCR，注意第三节坑 1

# ④ 验证
<bundle>/venv/Scripts/python.exe <bundle>/verify_bundle.py
```

## 五、外部工具依赖（不在包内，按需安装）

| 工具 | 状态 | 影响范围 |
| --- | --- | --- |
| ffmpeg | 本机已装 | 本包不直接使用，第三方扩展可用 |
| LibreOffice（soffice） | 未见安装 | 仅影响 pptx 模块的 `transform` 渲染 PDF/PNG 功能 |
| Tesseract OCR | 未装 | OCR 自动降级到 rapidocr，无需安装 |

## 六、移植边界（一句话版）

**本机内**：整个 bundle 文件夹拷到任何盘符/路径都能跑（`verify_bundle.py` 与 MANIFEST 入口均为自包含路径）。
**跨机器**：额外需要一个 Python ≥3.13 基础解释器，或按第四节重建 venv。
